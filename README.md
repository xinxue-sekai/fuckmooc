# fuckmooc

网课自动化工具，聚焦 **中国大学 MOOC**（icourse163.org），双击 `start.bat` 打开图形界面操作。用 Playwright 驱动本机浏览器完成视频、课件、测验等任务点；答题走「配置模型 → 题库 → 多引擎搜索 → 免费模型」多级降级策略。

> 只想要能用的版本？去 [Releases](https://github.com/xinxue-sekai/fuckmooc/releases) 下载压缩包，解压后双击 `start.bat`，界面里跟着引导走即可，详细步骤看包里的《使用说明.txt》。
> 本文档面向需要了解实现、改代码或排查问题的读者。

---

## 支持范围

| 能力 | 状态 |
|---|---|
| 图形界面 | ✅ 双击 `start.bat` 打开，任务清单按章折叠、关窗最小化托盘 |
| 视频 | ✅ 真实播放，2 倍速 |
| 文档 / 富文本 | ✅ 打开停留 |
| 章节测验 | ✅ 自动作答并交卷，配置模型 → 题库 → 搜索 → 免费模型 |
| 讨论区 | ✅ 自动生成并发表回复 |
| 作业 / 考试 | ❌ |

业务实现集中在 `platform/icourse163/`，`core/` 提供答题能力（题库、网页搜索、免费模型、完成记录、日志）与界面基础设施（本地服务、事件总线、上下文透传、配置读写）。图形界面通过 `gui.js` 把业务层接到同一个窗口，详见 [原理.md](原理.md) 第二部分。

## 安装

需要 **Node.js 22 或更高版本**，直接调用本机 Microsoft Edge（Windows 10/11 自带），不额外下载浏览器。

```bash
npm install
```

`npm install` 会装好 Playwright 与托盘组件 `systray2`。日常使用不需要命令行：解压发行包后双击 `start.bat`，它会检查环境、安装依赖，然后打开 `fuckmooc` 图形界面。

## 用法

双击 `start.bat` 打开图形界面，不会再弹出命令行黑框（`start.vbs` 以隐藏窗口方式运行 `node gui.js`，启动日志写到 `data/gui-stdout.log`）。左侧是「首页 / 课程 / 设置 / 记录 / 关于」：

- **首次打开**会进入一个纯净的配置向导：选平台（当前为中国大学 MOOC）→ 粘贴课程地址 → 可选配置答题模型 → 完成。向导必须走完（每一步都可以不填，随时可回退），之后随时在「课程」「设置」页修改；配置过的电脑不会再弹。首次运行还会在界面内安装运行依赖（黑框只负责装 Node.js），进度实时可见。

- **首页**：第一次打开会显示「还没添加课程」的空状态引导，点「添加课程」跳到课程页；选好课程后点「一键完成」，任务清单按章节展开、进度条实时更新，下方日志区按级别筛选、搜索、导出。
- **课程**：粘贴课程地址（浏览器地址栏整串复制）后点「添加」，可加多门、指定当前课程，最后点「保存课程」写入 `config.txt`。
- **设置**：外观主题（跟随系统 / 浅色 / 深色）、字号、关窗行为（每次询问 / 最小化到托盘 / 直接退出）、任务浏览器（后台最小化 / 前台可见）、答题模型（浮窗配置三种协议，可不配），以及「运行方式」里的只扫描 / 只做测验 / 跳过测验 / 演练 / 数量限制与节奏参数，改完点保存。
- **记录**：显示已完成任务、待重试、任务总数与运行日志份数，可分别清空完成记录、运行日志、登录态（都需二次确认）。
- **关于**：版本信息、创建桌面快捷方式（带应用图标）、免责声明与退出程序。

不带参数运行 `node start.js` 只会提示双击 `start.bat`；图形界面由 `start.bat` 或 `node gui.js` 打开，不再进入数字选择流程。关掉窗口只会最小化到系统托盘，任务继续在后台运行；要完全退出，请在「关于」页点「退出程序」，或在托盘菜单选「退出」。任务浏览器默认登录后最小化到任务栏（不抢焦点），可在设置切「前台可见」。

### 参数

命令行参数保留给高级用法与脚本调用，界面「设置 → 运行方式」里也有对应开关：

| 参数 | 说明 |
|---|---|
| `--probe` | 只扫描课程结构，打印任务点清单，不做任何操作 |
| `--limit=N` | 只处理前 N 个任务点（或前 N 个测验） |
| `--quiz` | 只做「测验与作业」页里的独立测验，不刷视频 |
| `--no-quiz` | 只刷视频和课件，跳过测验 |
| `--submit` | 配合 `--quiz` 使用，答完自动提交；不加则为演练模式 |

### 章节测验

一键完成默认会做两类测验，做完自动提交：

- **课后测验**：内嵌在章节详情里，没有「开始」环节，题目直接铺在页面上，底部就是「提交」。
- **单元测验 / 试题库**：在「测验与作业」页里，需要先勾选诚信条款再点开始，有 30 分钟限时。

不想让它碰测验就在「设置 → 运行方式」打开「跳过测验」，或命令行加 `--no-quiz`。想先看答案不提交：

```bash
node start.js icourse163 --quiz          # 只做「测验与作业」页的，演练模式
```

**为什么默认会提交**：一键完成的意义就是不用管，所以默认做完就交。但隔着两道闸——空题超过 20% 不交，单场超过 25 分钟停手。这两道闸对两类测验都生效。交卷前界面还会弹确认框，属于「危险动作分级确认」的一环，确认后才真正提交。测验和讨论一样，每条只做一次，失败也不重试——重来等于重新消耗机会 / 重复发帖。

### 讨论区

一键完成也会处理讨论：进话题 → 用 AI 生成 60~100 字回复 → 点发表。优先用配置的模型，不可用时退回免费模型。

内容刻意写得短、不带个人经历和专业背景——发在公开讨论区，越像随手一答越安全。不想让它发帖就改 `learn.js` 里的 `SKIP_TYPES`。

### 首次使用与登录态

登录态统一放在 `~/.fuckmooc/`（Windows 上是 `C:\Users\<你的用户名>\.fuckmooc\`）：

- `icourse163-profile`：课程登录

扫码一次之后免登录。放用户目录是为了换项目文件夹、重新解压新版本时不用重登。换账号时删掉对应目录。界面偏好存在 `data/gui-prefs.json`，不用手改。

**连扫码都省掉的办法**：先在 Edge 里正常登录课程，然后**完全退出 Edge**（不是最小化，是关掉所有窗口），再运行脚本。脚本会在启动前把你 Edge 里的登录数据导入自己的 profile，直接开始刷。

之所以要求退出 Edge，是因为浏览器运行时会锁住登录数据文件，复制不了。导入失败会自动回退到扫码，不影响使用。图形界面的 app 窗口用的是独立的 Edge 用户数据目录，不算这里的「Edge」；判断本机默认 Edge 时会按命令行把它排除掉。

答题模型走 OpenAI 兼容 API（「设置 → 配置模型」填入），不需要登录任何账号，也不会碰你的浏览器。

## 配置

复制 `config.txt.expample` 为 `config.txt`；图形界面会在「课程」「设置」页里替你写入，通常不用手改。

### 配置项

| 字段 | 说明 | 默认 |
|---|---|---|
| `ICOURSE_COURSE_URL` | 课程地址，多个用逗号或换行分隔 | 命令行参数优先 |
| `ICOURSE_ACTIVE_COURSE` | 当前选中的课程 `courseKey`，由界面「课程」页维护 | 空（取第一门） |
| `ICOURSE_PROFILE_DIR` | 登录态目录 | `~/.fuckmooc/icourse163-profile` |
| `ICOURSE_PLAYBACK_RATE` | 播放倍速，平台上限 2 | `2` |
| `ICOURSE_DOCUMENT_STAY_MS` | 文档停留毫秒数 | `35000` |
| `ICOURSE_OP_DELAY_MIN` | 操作间隔下限（毫秒） | `1200` |
| `ICOURSE_OP_DELAY_MAX` | 操作间隔上限（毫秒） | `2600` |
| `ICOURSE_QUIZ_BUDGET_MS` | 单场测验时间预算，超了就不交卷 | `1500000`（25 分钟） |
| `ICOURSE_QUIZ_MAX_MISS_RATIO` | 未作答比例超过这个值就不交卷 | `0.2` |
| `LLM_ENABLED` | 是否启用答题模型 | 「设置 → 配置模型」开关，默认关 |
| `LLM_PROVIDER` | 模型预设：deepseek / custom | 配置模型浮窗选择 |
| `LLM_PROTOCOL` | 接口协议：openai / anthropic / gemini | 配置模型浮窗选择，默认 openai |
| `LLM_BASE_URL` | OpenAI 兼容接口地址 | 配置模型浮窗填入 |
| `LLM_API_KEY` | 接口 API Key | 配置模型浮窗填入，留空跳过该层 |
| `LLM_MODEL` | 模型 ID（可从接口拉取列表） | 配置模型浮窗填入或拉取 |
| `RUN_PROBE` | 只扫描课程结构 | 界面「运行方式」维护，默认 false |
| `RUN_QUIZ` | 只做测验 | 界面「运行方式」维护，默认 false |
| `RUN_NO_QUIZ` | 跳过测验 | 界面「运行方式」维护，默认 false |
| `RUN_DRILL` | 演练（不交卷） | 界面「运行方式」维护，默认 false |
| `RUN_LIMIT` | 只处理前 N 项 | 界面「运行方式」维护，默认 0（不限） |

界面状态（引导完成标记、字号、外观主题）存 `data/gui-prefs.json`，由「设置」页维护；运行方式开关属于业务配置，与其它参数同存 `config.txt`。

## 答题策略

逐级降级，前一级拿不到才走下一级：

1. **答题模型**（`core/llm.js`）— 可选层。浮窗里选「API 协议」（OpenAI Chat Completions / Anthropic Messages / Gemini API）并填地址/Key/模型，可一键拉取可用模型列表。按量计费，答题一场通常几分钱；Key 没填、填错或欠费时自动停用这层并继续往下走。**不配置也完全能用**——下面三层已经覆盖绝大多数题目。
2. **题库检索**（`core/answer-bank.js`）— 题干拿去公开题库搜标准答案，命中且相似度 ≥ 0.9 直接采用。
3. **网页搜索**（`core/web-search.js`）— 题干丢进搜索引擎，抓回结果页正文，让模型从里面提取答案。引擎按健康度动态排序，连续失败 3 次的这一轮直接跳过；判断题会额外带上「判断题」关键词，带空括号的题会换成「什么」再搜一次。
4. **内置免费模型** — 纯推理兜底，无密钥。额度按出口 IP 计，用完就整场停用。

实测同一套 14 道题：搜索命中 14 道；纯模型只有 9 道和搜索结果一致，其中两道单选模型是明确答错的。所以搜索排在模型前面，顺序不能反。

**这里有个必须知道的坑：中国大学 MOOC 每次进入测验，选项顺序都会重新随机排列。** 同一道题这次「立大志」在 D，下次可能跑到 B。所以：

- 网络上搜到的「答案 B」不能直接用；
- 题库返回的答案字母也不能直接用；
- 唯一可靠的做法是把答案还原成**选项文字**，再按文字匹配当前页面的选项。

代码里搜索和题库两条路径都遵循这条规则：题库走 `mapAnswer()`，搜索走 `mapByText()`，都是先比对文字再取字母。配置模型是例外——选项列表是原样发给它的，所以它回的字母直接就是页面上的 key。

**关于隐私**：这几条路都要把题干发到外部——配置的模型、题库接口（hive-net.cn）、搜索引擎（搜狗、百度）。脚本不会发送账号、密码或学号，但题干内容确实会离开你的电脑。介意的话可以不跑测验，只刷视频和课件。

实现细节、页面结构、踩过的坑见 [原理.md](原理.md)。

## 已知限制

- 中国大学 MOOC 的章节测验，一键完成会自动提交。该平台每个测验只有 3 次有效提交且取最高分，答错没有补救；想先看答案就在「设置 → 运行方式」打开「演练（不交卷）」，或加 `--no-quiz` / `--quiz` 演练。
- 脚本的浏览器 profile 放在 `~/.fuckmooc/` 下，与日常浏览器完全隔离；免扫码时只导入登录 Cookies 和解密密钥，不复制扩展配置，不会安装或改动你本机的浏览器插件。
- 断网或课程浏览器被手动关掉时，界面会弹可关闭提示或阻断窗口，不会静默卡死；已完成的记录会保留，恢复后重新运行会跳过已完成项。
- **讨论区会自动发帖**：内容由 AI 生成、带你的用户名、公开发布且撤不回来。每条只发一次，失败也不重试。不想让它发帖就把 `learn.js` 里的 `SKIP_TYPES` 改成 `new Set(['讨论'])`。
- **危险动作分级确认**：自动交卷、讨论发帖、清空记录等不可逆操作会在界面弹确认框，按危险等级分级拦截，确认后才执行；即使任务在后台运行也不会自动放行。可勾选「本次运行不再提示」，但每次新任务仍重新确认。
- 关窗只是最小化到托盘、任务继续，不会自动结束；需要显式在「关于」页或托盘菜单退出。托盘依赖 `systray2`，被安全软件拦截时托盘可能不出现，但服务照常常驻、重复双击可唤回窗口。
- 图形界面需要 Node.js 22+ 与本机 Microsoft Edge；界面用 Edge `--app` 独立窗口，业务用 Playwright 持久化 profile，两者各用各的用户数据目录。
- 作业和考试不处理（需要提交附件或限时答题，风险太高）。
- 免费模型响应时间波动大，同一道题可能 1 秒也可能接近 1 分钟。
- 强依赖页面 DOM 结构，平台改版即失效。
