============================================================
                    fuckmooc  使用说明
============================================================

自动刷网课的小工具，帮你把视频看完、课件翻完、课后测验做掉。
适用于中国大学 MOOC。
带图形界面，双击 start.bat 就能用，不需要敲命令。
不需要申请任何 API Key。


------------------------------------------------------------
  第一步  双击 start.bat
------------------------------------------------------------

会打开一个 fuckmooc 窗口，不会再弹出黑色命令行窗口。
左侧是「首页 / 课程 / 设置 / 记录 / 关于」几个页面，
点一下就能切换。

第一次打开会先进入配置向导：选好平台、把课程地址粘贴进去，
想配模型就点「配置模型」，不配也能一路「下一步」。向导必须
走完，随时点「上一步」回退，这些以后都能在「课程」「设置」页改。

没装 Node.js 的话，它会自动帮你装好（需要 22 或更高版本）。
装完提示你关掉窗口、重新双击一次。

首次运行还会在界面里安装运行依赖，大约 1~3 分钟，进度实时
可见，这一步只需要一次。

向导完成后，会自动在桌面创建一个带应用图标的快捷方式，
以后双击桌面图标就能打开；没创建成功的话，到「关于」页
点「创建桌面快捷方式」即可。

自动安装失败的话，去 https://nodejs.org/zh-cn
下载 LTS 版本（22 或更高），双击安装，一路点下一步。

重复双击 start.bat 不会开出第二个程序，只会把已经开着的
窗口叫回前台。


------------------------------------------------------------
  第二步  第一次打开：添加课程
------------------------------------------------------------

第一次打开，首页会显示「还没添加课程」，点上面的「添加课程」
按钮，会跳到「课程」页。

【添加课程】在「课程地址」里粘贴课程页面地址：
打开课程页面，把浏览器最上面那一栏从 https 开头整串复制过来，
粘进去就行。可以加好几门，界面里会列出来，点一门设为当前课程。

粘进去后点「添加」，这门课会出现在列表里，点「设为当前」
可以指定这次跑哪一门。改完记得点「保存课程」，不保存不生效。

不用手动改 config.txt，界面会替你保存。
配置文件叫 config.txt，放在程序文件夹里，里面有你的课程地址等信息，
别发给别人。


------------------------------------------------------------
  第三步  开始跑
------------------------------------------------------------

回到「首页」，点「一键完成」。

任务清单会按章节一条条列出来，展开某一章就能看到这章下面
的视频、课件、测验和讨论；下面「运行日志」区实时显示进度，
可以按级别筛选、搜索、导出，也可以收起。

跑的过程中顶部有「暂停」「停止」两个按钮，随时能点。


------------------------------------------------------------
  关掉窗口不会停
------------------------------------------------------------

点窗口右上角的 X，只是把界面最小化到系统托盘，任务继续在
后台跑。右下角托盘图标右键可以「显示主窗口」「暂停 / 继续」
「停止」「退出」。

想让程序彻底退出，请到「关于」页点「退出程序」，或者在托盘
右键选「退出」。只关窗口不等于退出。

托盘图标用到的组件叫 systray2，个别安全软件会误报拦截。
就算托盘没出现，程序也照样在后台跑，再双击一次 start.bat
就能把窗口叫回来。


------------------------------------------------------------
  关于测验（重要）
------------------------------------------------------------

「一键完成」会把视频、课件、课后测验、讨论一次做到底。

中国大学 MOOC 每个测验只有 3 次提交机会，取最高分。
所以脚本加了两道保护，不会乱交：

    - 空题超过两成（14 题空 3 题）就不交，机会给你留着
    - 单场超过 25 分钟自动停手，不会拖到平台超时

交卷前界面还会弹一次确认框，你点了「确认交卷」才会真的交；
这类撤不回来的动作都会先问一句。

答题顺序是：配置模型（开了才用）→ 题库 → 网上搜索 → 免费模型。
搜到的答案会按选项内容去对，不是照抄字母 —— 这个平台每次进
测验，选项顺序都会重新打乱。

只想刷视频、不想碰测验，到「设置」页「运行方式」里把「跳过
测验」打开；想先看看答案不交卷，把「演练（不交卷）」打开。


------------------------------------------------------------
  关于讨论（注意看）
------------------------------------------------------------

「一键完成」也会去讨论区发帖：进话题、让 AI 写一段
60~100 字的回复、点发表。

有两件事得说清楚：

    - 讨论是公开发布的，带你的用户名，发出去撤不回来
    - 每条讨论只发一次，失败也不会重发

发帖前同样会弹出确认框。内容刻意写得短、不带个人经历，
像随手回一句。不想让它发帖的话，把 platform/icourse163/
learn.js 里那行 SKIP_TYPES 改成 new Set(['讨论']) 就行。


------------------------------------------------------------
  关于答题模型（可选，默认关）
------------------------------------------------------------

到「设置」页点「配置模型」，默认不启用也能正常答题：
题库、网上搜索、免费模型三层已经够用。

想启用的话，填一个模型接口（OpenAI 兼容，不操作任何网页，
也不会碰你的账号登录态）：

    1. 预设「DeepSeek 官方」：打开 platform.deepseek.com
       注册并创建一个 API Key，充值几块钱够用很久
    2. 预设「自定义」：填任意 OpenAI 兼容接口的
       地址、Key 和模型名
    3. 点「获取可用模型」可以直接拉取模型列表
    4. 勾上「启用」，保存即可

之后答题会先问这个模型，准确率更高。不想用了回「设置」页
把开关关掉即可。Key 填错或者欠费了，脚本会自动停用这一层，
继续用其他方式答题，不会卡住。


------------------------------------------------------------
  跑的时候注意什么
------------------------------------------------------------

别关那个自动打开的浏览器窗口，可以最小化。
中途关掉也没关系，下次运行会跳过已完成的部分。

中国大学 MOOC 第一次会弹出二维码，用手机扫一下，
以后就不用了。登录状态存在用户目录的 .fuckmooc 文件夹里，
换项目文件夹、重新解压新版本都不用重登。


------------------------------------------------------------
  记录页能做什么
------------------------------------------------------------

「记录」页能看到已完成多少任务、还有多少待重试、一共有多少
任务点、攒了多少份运行日志，以及是否已经保存登录态。

下面三个按钮分别清空完成记录、运行日志、登录态，每个都会
先弹一次确认框。清空后无法恢复，清掉登录态需要重新扫码。


------------------------------------------------------------
  出问题怎么办
------------------------------------------------------------

中途断网：界面会弹一条黄色提示，任务停下来，已完成的记录
还在。网络恢复后重新点「一键完成」即可，不会重做已完成的。

课程浏览器被关掉：界面会弹一个阻断窗口，选「重新打开并
继续」会重开浏览器接着跑，选「停止任务」就结束。

交卷前都会弹确认框。勾了「本场不再提示」也只在这一次任务
里有效，下次启动还会再问。


------------------------------------------------------------
  常见问题
------------------------------------------------------------

问：打开后弹出一堆插件安装页
答：脚本只会读取登录 Cookies，不会复制浏览器扩展配置，
    也不会安装或改动你本机浏览器里的插件。
    如果之前用过旧版本，重新登录一次即可。

问：双击后窗口一闪就没了
答：电脑没装 Node.js，而且自动安装失败了。
    去 https://nodejs.org/zh-cn 装好 22 或更高的 LTS 版本再试。

问：界面卡在「还没添加课程」
答：到「课程」页粘贴课程地址，点「添加」，再点「保存课程」，
    然后回首页点「一键完成」。只粘贴不保存不会生效。

问：点 X 关了窗口，任务还在跑吗
答：在。窗口只是最小化到托盘，到「关于」页点「退出程序」
    才会真正结束。

问：登录时没看到二维码
答：在登录框里找「手机扫码，安全登录」切换一下。

问：视频播着播着不动了
答：把浏览器窗口点开，别最小化。

问：会被老师发现吗
答：平台有完整记录，视频带你的账号水印，
    播放时长和提交次数都能查。脚本只负责自动化，
    改变不了这些记录。用不用请自己判断。
